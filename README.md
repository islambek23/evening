# Тихий вечер

Веб-страница поддержки после рабочего дня: подбадривающие ответы, «Выговориться», перерыв и напоминания. Без базы, входа и сохранения данных: всё исчезает при закрытии вкладки.

- Запуск: `npm start`, затем http://localhost:8080
- Тесты: `npm test`
- Тексты: `public/support.js`, материалы перерыва: `public/breaks.js`
